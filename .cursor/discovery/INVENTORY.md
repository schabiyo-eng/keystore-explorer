# Swing action inventory

Recrawl of KeyStore Explorer Swing (Phase 2). Copied leftover discovery files in git were **not** treated as signed.

**Sources (read `doAction()` and helpers it calls):**

- `kse/src/main/java/org/kse/gui/KseFrame.java` — menubar, tab/keystore/entry context menus, action wiring
- `kse/src/main/java/org/kse/gui/actions/*Action.java` except `KeyStoreExplorerAction`
- Dialog types constructed in `doAction()` or a helper that `doAction()` always calls
- Shared password UI lives on `KeyStoreExplorerAction` (`DGetPassword`, `DGetNewPassword`, `DInitPasswordManager`, `DUnlockPasswordManager`, `DProblem`)

**Conventions**

- One row per action class (98). Abstract bases `AuthorityCertificatesAction`, `AuthorityCertificatesVerifyAction`, and `OpenMsCapiAction` are included.
- `CopyKeyPairAction` / `CopyTrustedCertificateAction` / `CutKeyPairAction` / `CutTrustedCertificateAction` do not override `doAction()`; they inherit the parent implementation.
- Key context Cut/Copy wire `CutAction` / `CopyAction` directly (there is no `CopyKeyAction` / `CutKeyAction`).
- `DError.displayError` is the catch-all exception dialog on most actions; it is omitted from the dialogs column unless it is the only UI.
- `skipReason` is required when tag is `skip` or `platform`.
- Menu paths use `KseFrame` resource labels (`File`, `Edit`, `View`, `Tools`, `Examine`, `Help`) plus context menus (`Key Pair`, `Trusted Certificate`, `Key`, `multi-entry`, `tab`).
